# Feature Specification: Agent 与创作工作台可靠性

**Feature**: 003-agent-workspace-reliability（无 Git 分支）
**Created**: 2026-09-06
**Status**: Implemented and verified
**Input**: 继续完成整个 Agent 链路和前端处理优化，保留 FastAPI 与真实 Unity 创作流程。

## User Scenarios & Testing

### US1 持续讨论且不覆盖制作 (P1)
创作者长期打磨同一个游戏，制作期间不能从另一标签页改变正在执行的方案。
独立验收：活跃任务拒绝编辑，模型请求期间出现任务也不保存陈旧结果；长对话仍能继续，历史记录不被删除。
1. 制作中发送或整理方案，服务拒绝且不产生模型调用/草稿变化。
2. 模型思考期间任务开始，返回结果不能覆盖正在制作的草案。
3. 长对话继续可用，已保存对话与参数不丢失，输入刷新可恢复。

### US2 看懂并控制 Agent 执行 (P1)
用户看到真实执行步骤，能暂停、继续或停止，并理解动作何时生效。
独立验收：实际事件映射步骤；暂停恢复重用已完成动作；停止后不发布。
1. 显示理解方案、场景/素材、检查、构建等实际步骤，不编造百分比。
2. 暂停或停止正在进行的操作时提示等待安全边界；暂停后提供继续入口。
3. 重试保留实际失败原因，终止不会继续发布；工具重复或并发执行风险通过测试约束。

### US3 工作台状态可靠同步 (P1)
部分读取失败不妨碍查看任务，网络恢复自动清除连接提示，跨标签页能看到新方案。
独立验收：辅助请求失败时任务状态继续更新；陈旧轮询不覆盖确认/取消结果；失败/刷新保留输入。
1. 素材或历史请求失败，任务和试玩继续更新并保留可用数据。
2. 操作后旧读取响应不倒退状态；新对话版本自动同步。
3. 连接错误与操作错误分开呈现，不错误声称未加载数据已保存。

### US4 素材和试玩信息一致 (P2)
用户能分辨最新候选与历史候选，素材仓库准确显示当前游戏使用的图片。
独立验收：新方案优先、旧方案可查；真实发布素材的仓库行显示已使用，旧版恢复同步标记。

## Requirements
- FR-001 服务端保护制作中的方案，包括模型调用前后竞态。
- FR-002 移除长期项目的固定对话死锁上限；模型上下文有界且完整历史保留。
- FR-003 展示实际 Agent 步骤及恢复信息，错误不虚报成功。
- FR-004 提供明确暂停/继续/停止处理，保证控制与发布一致。
- FR-005 独立恢复工作台各数据源；阻止旧响应覆盖新状态。
- FR-006 保存未发送草稿，跨标签页同步最新方案而不覆盖输入。
- FR-007 素材候选分组、仓库实际使用状态与发布版本一致。
- FR-008 补充关键失败回归、桌面/手机验证、真实 Agent/Unity 链路，并更新运行文档。

## Key Entities
既有 DesignDocument、Run、AgentCheckpoint、RunEvent、ArtPlan；新增前端草稿和连接/步骤投影，不取代服务器事实源。

## Edge Cases
慢响应、部分请求失败、刷新/切页、制作期间聊天、跨标签页确认、暂停/取消安全边界、动作重放、重复终态事件、缺少素材计划的旧项目。

## Success Criteria
- SC-001 准入竞态与长对话回归通过，不产生额外制作任务。
- SC-002 部分断网/旧响应/草稿恢复/跨标签页 UI 测试通过。
- SC-003 Agent 控制、失败/恢复与步骤投影测试通过，真实 Unity 至少完成一次流程回归。
- SC-004 素材当前使用与最新候选的桌面和手机验证通过。

## Assumptions
继续单人 2D Runner，本轮优化现有 Agent/前端全链路，不扩张到任意游戏生成或商业部署。Unity 操作遵循已实现安全边界，不能把请求停止等同引擎立即退出。
